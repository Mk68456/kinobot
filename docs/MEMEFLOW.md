# MemeFlow — локальная мастерская Shorts

Отдельное окно для коротких мемов. Программа не запускает KinoTime-бота и не подключается
к облачным сервисам. Распознавание речи и субтитры не используются.

## Запуск на этом компьютере

Двойной щелчок по `tools/Start-MemeFlow.cmd`.
Для свежей установки в существующем окружении проекта достаточно:

```powershell
.\.venv\Scripts\python.exe -m pip install -r tools/memeflow_requirements.txt
```

Пока программа использует Python-окружение этого компьютера. Перенос на другой компьютер
и сборка отдельного EXE — следующий этап после проверки монтажа.

## Как пользоваться

1. Нажмите «Добавить видео» и выберите несколько коротких мемов.
2. Выберите игровой фон. Он начинается с начала для каждого результата и зацикливается,
   если мем длиннее него. Используется исходная длительность мема, включая уже существующую
   в исходнике концовку: программа не удаляет её автоматически.
3. Переключайте «Круг» / «Скруглённый прямоугольник». Ползунки меняют размер окна,
   положение по вертикали и расположение кадра внутри маски.
4. Фиолетовый баннер Telegram Stars выбран по умолчанию. Его можно заменить GIF, MP4, WebM, MOV, PNG,
   JPG или WebP. Переключатель полностью отключает рекламный слой.
   «Убрать зелёный фон баннера» включайте только для баннеров с зелёной подложкой.
   «Плавное появление» добавляет одну секунду только фона, затем окно мема и баннер
   появляются за 0,6 секунды. Мем и его звук начинаются после первой секунды;
   итоговый ролик становится на секунду длиннее. Настройку можно отключить.
5. Выберите папку результатов и качество 720 либо 1080. Выходной формат — вертикальный
   MP4 9:16, H.264, 30 кадров/с. 720 обрабатывается быстрее на ноутбуке.
6. Выберите строку мема в очереди. Справа появится кадр предпросмотра; временной ползунок
   позволяет проверять другие моменты. Это просмотр отдельных кадров, а не видеоплеер.
7. Нажмите «Создать Shorts». Каждый файл обрабатывается отдельно. Ошибка одного файла
   не останавливает оставшиеся. «Стоп» отменяет текущий файл и оставшуюся очередь.
8. Готовые ролики открываются через «Папка» или «Открыть выбранный результат».

Важные детали:

- Звук берётся только из первой звуковой дорожки мема. Фон и баннер всегда без звука в результате.
- Баннер повторяется на протяжении всего ролика, располагается вверху и не создаёт отдельную заставку.
- Настройки одинаковы для всей очереди. Для мемов с разной композицией можно сделать отдельные проходы.
- Круг и прямоугольник заполняются кадром с обрезанием краёв. Проверьте предпросмотр, чтобы
  не потерять лица, надписи или важные детали; для широких мемов часто удобнее прямоугольник.
- Вшитые в исходник надписи, водяные знаки и монтаж сохраняются. Нужен чистый исходник,
  если их не должно быть в результате.
- Баннер может перекрыть мем при чрезмерном перемещении окна вверх. Это видно в предпросмотре.
- Видео сохраняются под уникальными именами, исходники не изменяются. Рядом создаётся
  JSON с параметрами монтажа. Промежуточный MP4 удаляется при ошибке или отмене.
- Настройки сохраняются в `runtime/memeflow/settings.json`.

«Тестовый пример» создаёт короткий абстрактный фон и тестовый мем. Это проверка работы
программы; для публикаций замените их своими материалами.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m unittest tests.test_meme_render -v
```

Проверяются реальный экспорт, оба типа маски, повтор короткого фона и баннера,
предпросмотр после окончания первого прохода фона, сохранение звука только из мема,
тихий исходник, отмена и сохранность исходных файлов.
