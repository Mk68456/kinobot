# KinoTime 1.4.7 — Jackett и выбор трекеров

Обновите лаунчер установщиком или переносным EXE версии 1.4.7. Jackett 0.24.2910
включён в обе сборки. Отдельно устанавливать его не нужно.

## Настройка

1. Откройте **Торренты → Помощник выбора раздачи → Источники…**.
2. Нажмите **Запустить встроенный**, затем **Настроить трекеры**.
3. Откроется локальная страница Jackett. Добавьте нужные трекеры. Для LostFilm,
   RuTracker и других источников с авторизацией укажите собственные данные входа
   в настройке соответствующего трекера и проверьте его подключение.
4. Вернитесь в лаунчер, нажмите **Обновить список**. Галочки появляются для
   настроенных в Jackett источников. Новый источник автоматически не выбирается.
5. Отметьте нужные источники и нажмите **Сохранить выбор**. Для поиска только
   в LostFilm оставьте только **LostFilm.tv**, снимите **Rutor — встроенный поиск**.

Rutor продолжает работать без Jackett через существующий механизм поиска.
При выбранных источниках Jackett встроенный компонент при необходимости
запускается автоматически. Список и выбор сохраняются между запусками лаунчера.
В таблице результатов есть колонка **Трекер**. Одинаковые раздачи с одинаковыми
сведениями объединяются по хешу, а разные описания сохраняются для проверки.
Ошибка одного источника не останавливает поиск в других; ошибки видны в деталях.

Поиск выполняется только по отмеченным источникам. Если Jackett недоступен,
поиск не переключается на другие трекеры без вашего выбора.

## Поиск, скачивание и ограничения описаний

Название, сезоны, разрешение, озвучка, максимальный размер и условие отсутствия
рекламы применяются к общей таблице. Неизвестное значение не считается совпадением.
Включите **Показать исключённые**, чтобы увидеть причины отклонения.

Некоторые трекеры отдают через Jackett только название, размер и ссылку. В этом
случае полнота описания не выдумывается. Если условие отсутствия рекламы вам не
требуется, снимите его галочку. Для LostFilm озвучка помечается по источнику раздачи,
но сведения о кодеке и числе аудиодорожек не предполагаются. Ручное скачивание
доступно при соблюдении обязательных условий; автоматический подбор дополнительно
требует достаточных сведений об исходнике.

LostFilm может возвращать оригинальные английские названия. Для точного
сопоставления ищите по оригинальному названию, например `The Boys`. Названия
формата `The Boys - S01E01 - Episode - 1080p` распознаются как серии `The Boys`.
Раздачи отдельных серий отображаются отдельно, их нельзя считать полным сезоном.

**Страниц Rutor** ограничивает только существующий поиск Rutor. Jackett возвращает
доступную ему выдачу каждого выбранного трекера одним поисковым запросом;
лаунчер обрабатывает до 1000 результатов каждого трекера и сообщает о лимите.
Это не гарантирует просмотра всех страниц сайта.

**Скачать выбранную раздачу** получает исходный `.torrent` через Jackett, сохраняя
адреса трекера и данные доступа в нём. Если источник предоставляет magnet,
поддерживается и этот вариант. Затем qBittorrent получает список файлов, выбирает
нужные сезоны и выполняет скачивание. Материал передаётся в обычную очередь
проектов. Карточка каталога на этом этапе не нужна.

## Локальный компонент

Встроенный Jackett слушает только `127.0.0.1:9118`, не устанавливает службу Windows
и не меняет настройки существующего Jackett. При первом запуске файлы копируются
в стабильную папку рядом с настройками лаунчера, поэтому переносной EXE можно закрыть
без потери файлов компонента. Jackett продолжает работать фоном после закрытия окна
поиска. Его можно завершить как обычный процесс JackettConsole в диспетчере задач.

Данные встроенного компонента хранятся в `%LOCALAPPDATA%/KinoTime/Launcher/jackett-data`
для EXE; запуск из исходников использует папку состояния исходного лаунчера.
Переопределение `KINOTIME_STATE_DIR` также применяется. Настройки аккаунтов
и API-ключ встроенного Jackett хранит сам Jackett. Они не включаются в сборку.
Ключ своего Jackett хранится только в памяти текущего окна поиска.

Для подключения уже установленного Jackett укажите его локальный адрес,
например `http://127.0.0.1:9117`, и API-ключ из его страницы настроек.
Удалённые адреса и передача ключей на сторонние сайты не поддерживаются.
Если порт 9118 занят другим приложением, подключите существующий Jackett
по его адресу вместо запуска второго экземпляра.

Обновление сервера относительно 1.4.6 не требуется. Для создания карточек новых
сериалов по-прежнему нужен серверный импорт из обновления 1.4.6.
