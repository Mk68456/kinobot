# Порядок серий в сезоне

Обновите database/categories.py и webpanel/repository.py в проекте на хостинге, затем перезапустите бот. Обновите веб-панель через Ctrl+F5; в Telegram заново откройте сезон.

Серии теперь отображаются по номеру в названии, а не по времени добавления: Серия 1, Серия 2, …, Серия 40. Порядок одинаков в веб-каталоге, списке серий, страницах и кнопках предыдущей/следующей серии. Изменения применяются и к уже опубликованным сезонам.

Распознаются названия вида «Серия 40: …», «Эпизод 40», «Episode 40», «S02E40», «40 - Название». Файлы без распознаваемого номера остаются в порядке добавления после нумерованных. Порядок вариантов фильмов не меняется.

База не переписывается. ID серий, качества, файлы и отметки просмотра сохраняются. Архив не содержит базы и настроек.
