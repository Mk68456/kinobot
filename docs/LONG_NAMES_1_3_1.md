# KinoTime 1.3.1: длинные названия

Убрано ограничение в 120 символов для названий папок, вариантов видео, сезонов и серий. Лаунчер и веб-панель сохраняют названия целиком; одинаковое начало длинных названий больше не приводит к их обрезанию и объединению разных серий.

## Установка

1. Закройте лаунчер после завершения текущей операции. Готовые MP4, исходники и журналы очереди оставьте на месте.
2. На сервере остановите бота. Из `KinoTime-Server-1.3.1.zip` перенесите содержимое папки `Server` в корень проекта, заменяя только файлы из архива. В нём только код и интерфейс; рабочей базы, настроек и видео нет. Не заменяйте папку `database` целиком.
3. Полностью перезапустите бота. Обновите страницу панели сочетанием Ctrl+F5.
4. Обновите программу установщиком `KinoTime-Setup-1.3.1.exe` или замените самостоятельный `KinoTime.exe`. Для запуска из исходников файлы находятся в `Source/tools`. Настройки и идентификатор компьютера сохраняются.
5. Вернитесь к той же папке и выбранным качествам. Повторите «Подготовить без отправки»: неизменённые готовые копии используются из кэша, без повторного кодирования. Затем продолжите настройку и отправку. Уже принятые ботом файлы сохраняют свои идентификаторы и пропускаются при передаче.

Если используете Python-лаунчер, небольшой архив `KinoTime-LongNames-1.3.1.zip` содержит обе части: `Server` для хостинга и `Launcher` для компьютера. Перенесите содержимое `Launcher` в папку проекта лаунчера с заменой кода. Его настройки и журналы в архив не входят. Запускайте обновлённый лаунчер привычным способом. Для готового EXE используйте Windows-архив, а не замену Python-файлов рядом с EXE.

Для очереди, которая остановилась именно на ошибке «Сократите названия папок и вариантов до 120 символов», повторный импорт должен пройти после серверного обновления. Не удаляйте готовые копии, чтобы начать заново.

Ранее сохранённые пользовательские названия существующих черновиков не переписываются автоматически. Если старый лаунчер уже обрезал название серии, его можно восстановить вручную в панели. Для новых импортов используются полные названия.

Обновление сохраняет возможности версии 1.3.0 для нескольких компьютеров. При переходе с более старой версии следуйте также `INSTALL-MULTIPC.md` из общего архива: обновите все лаунчеры и получите отдельный код `/desktop` для каждого ПК.

Лимиты количества файлов, размера запроса и допустимого пути остаются прежними. Названия проекта (200 символов), качества и озвучки — отдельные поля; это исправление касается папок и названий файлов в каталоге.

Полные названия хранятся в каталоге. Если подпись отправляемого файла превышает лимит Telegram в 1024 символа, бот сокращает только эту подпись, сохраняя доставку файла и кнопки. Ограничение Telegram описано в [Bot API](https://core.telegram.org/bots/api#sendvideo).

## Проверка

Тесты проверяют длинные вложенные пути, полные подписи, редактирование сезонов, публикацию, переименование папок и файлов, сохранность Telegram file_id при повторном импорте и разные серии с одинаковыми первыми 120 символами. Веб-интерфейс проверяется на локальных тестовых данных. Рабочая база и сервер BotHost во время проверки не изменяются.
