# Восстановление связи с API

Закройте лаунчер, распакуйте архив в его папку с заменой файлов и запустите снова.

Повторы запросов при временном обрыве сохранены. Добавлена обработка оборванных HTTP-ответов, некорректного JSON и указания Retry-After от сервера. После успешного повтора отображается восстановление связи. Индикатор подключения телефона показывает потерю связи при ошибке фоновой проверки.

Новый код подключения нужен при ошибке авторизации; временный сетевой тайм-аут не требует смены кода. Исправление не гарантирует доступность сервера или сети. При длительном обрыве следует проверить доступность веб-панели в браузере на этом компьютере.

Включено предыдущее исправление статусов остановленной подготовки. Базы, настройки и видео в архив не включены.
