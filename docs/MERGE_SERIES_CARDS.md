# Объединение карточек сериалов

## Установка

Замените файлы из архива в проекте на хостинге с сохранением папок, перезапустите бот и обновите веб-панель через Ctrl+F5. Новый файл webpanel/catalog_merge.py обязателен. Бота не удаляйте. Действующую базу и постоянный том сохраните; в архиве нет базы, настроек или видео.

## Как объединить 1024 и 1014

1. В каталоге у карточки с кодом 1014 нажмите «Объединить карточки». Эта карточка будет основной: её код, название, постер и описание останутся.
2. Укажите код 1024 как переносимый.
3. Нажмите «Проверить объединение». Будут показаны количество сезонов и серий, совпадения и конфликты.
4. Если конфликтов нет, нажмите «Подтвердить объединение».

После переноса останется одна карточка с кодом 1014. Видео повторно не загружаются. Выполнить объединение можно только для двух сериалов/мультсериалов в одном разделе каталога.

## Правила

- Сезоны сопоставляются по номеру, а при отсутствии номера — по названию.
- Серии сопоставляются по номеру в названии, а при отсутствии номера — по полному названию.
- Для разных сезонов и серий сохраняются их ID.
- Совпадающие серии объединяются: качества и отметки просмотра переносятся в серию основной карточки.
- Если одно качество с одной озвучкой указывает на разные файлы, объединение запрещено. Исправьте подписи качества или озвучки в карточках, чтобы снять конфликт.
- Одинаковые варианты одного файла не дублируются.
- Несколько записей одного сезона или серии внутри одной карточки требуют предварительного исправления.
- Ссылки опубликованных черновиков и черновики добавления серий переводятся на основной код. Принятые Telegram-файлы сохраняются.
- Если карточки изменились после предварительной проверки, необходимо проверить объединение снова.

Перенос выполняется одной транзакцией: при ошибке изменения отменяются. Перед объединением рекомендуется сохранить резервную копию действующей базы. Автоматической кнопки отмены объединения нет.

Удаляемый числовой код больше не используется: старые ссылки с ним перестанут работать. Если у обеих карточек есть отдельные ссылки доступа, сохраняется ссылка основной карточки; если такая ссылка есть только у переносимой, она начинает вести на основную карточку. Права доступа переносятся.
