# KinoTime 1.4.6: скачивание исходников в очередь проектов

Поиск раздач — этап получения исходников. Для скачивания нового сериала карточка
в каталоге не требуется. Поле кода карточки удалено из окна поиска.

## Рабочая цепочка

1. Пользователь отправляет заявку; администратор принимает её в работу.
2. Администратор открывает **Торренты → Помощник выбора раздачи**, вводит название
   и обязательные условия, нажимает **Найти варианты**.
3. Администратор выбирает строку и нажимает **Скачать выбранную раздачу**.
   Сведения о полноте сезона из описания не являются обязательными для ручного
   выбора: список файлов проверяется через qBittorrent до скачивания содержимого.
4. После скачивания исходники автоматически добавляются в **Очередь проектов**.
   Открывается этот раздел, начинается обычная подготовка выбранных качеств и звука.
   Для скачивания и подготовки подключение к панели и код карточки не нужны.
5. Когда MP4 готовы, администратор подключает панель и нажимает **Создать карточки**,
   оформляет карточку в WEB и запускает **Отправить**. Публикация остаётся отдельной.

Настройки качеств берутся из раздела «Источник» при запуске скачивания и фиксируются
для задания. Скорость, папка, резерв места и авторизация qBittorrent задаются как
раньше. Новый проект попадает в обычный планировщик с общей настройкой параллельности,
паузой, продолжением и сохранением готовых результатов. Старый раздел «Очередь»
переименован в «Очередь файлов», раздел «Проекты» — в «Очередь проектов».

Подготовка может выполняться параллельно со скачиванием следующего проекта.
Торрент-очередь хранит идентификатор переданного проекта; повторное продолжение
после сбоя не создаёт дубликат. Управлять подготовкой нужно в «Очереди проектов».

## Несколько сезонов

Поле **Сезоны** принимает:

- `0` — фильм;
- `1` — один сезон;
- `1-3` — диапазон;
- `1,3,5` — выбранные сезоны;
- `все` — все найденные сезоны в пределах просмотренных страниц.

Сборники нескольких сезонов больше не отсекаются, если содержат нужные сезоны.
При скачивании сборника выбираются только нужные сезоны по именам файлов.
Имена S01E01, 1x01, а также номера серий внутри папок Season 1/Сезон 1 поддерживаются.
Неоднозначные имена или повторные варианты одной серии останавливают автоматический
выбор файлов и оставляют задачу для ручного выбора.

**Найти и скачать** подбирает раздачи, покрывающие выбранные сезоны, и не скачивает
один сезон дважды из разных выбранных раздач. Если покрытия нет, показывается список
сезонов, для которых нет подходящих раздач. **Скачать выбранную раздачу** скачивает
нужные сезоны только из выделенной строки. Несколько сезонов одного сборника
становятся одним новым проектом и одной карточкой с сезонами для каждого файла.
Разные раздачи становятся отдельными проектами; при необходимости карточки затем
можно объединить существующими средствами WEB-панели.

Описание раздачи не доказывает полноту или правильность озвучек. Отсутствие заявленного
числа серий больше не блокирует скачивание: проверка и оформление выполняются дальше
по обычному сценарию. Постоянное слежение за выходом новых серий не включено.

## Обновление сервера для создания новых карточек

Скачивание и локальная подготовка работают после обновления EXE.
Для кнопки **Создать карточки** нового сериала требуется обновить серверный импорт.

1. Остановите бота обычным способом.
2. Из отдельного серверного архива перенесите `Server/webpanel/imports.py`
   в `webpanel/imports.py` папки бота с заменой файла.
3. Запустите бота снова.

Изменений схемы базы и переноса пользовательских данных нет. Архив не содержит
настроек, базы, токенов или видео. Сервер создаёт только черновик нового сериала
с номерами сезонов у файлов; запись в каталоге появляется после обычной публикации.
Заявка пользователя не связывается с проектом автоматически по одному названию:
для отдельно добавленного материала используется существующее завершение заявки
по коду опубликованной карточки.
