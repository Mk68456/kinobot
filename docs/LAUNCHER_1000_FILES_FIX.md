# До 1000 файлов и точный расчёт очереди

Обновление устанавливается на компьютер и сервер. Миграция базы не требуется.

## Установка

1. Остановите очередь и закройте лаунчер.
2. В папке лаунчера на компьютере замените с сохранением структуры:
   - `tools/desktop_launcher.py`
   - `tools/torrent_queue.py`
   - `tools/torrent_panel.py`
3. На сервере замените только файлы кода:
   - `webpanel/imports.py`
   - `webpanel/repository.py`
   - `webpanel/server.py`
   - `webpanel/static/app.js`
4. Полностью перезапустите бот на сервере, затем запустите лаунчер. В браузере обновите WEB-панель через Ctrl+F5.

В архиве нет базы SQLite, настроек, токенов, пользовательских файлов и журналов. Папку `database` заменять не нужно. Сохраняйте текущие параметры хранения и `DATABASE_PATH`, готовые видео, журналы очереди и настройки лаунчера. Тестовые файлы не нужны для запуска.

## Как считается количество

Для каждого исходника: число подходящих выбранных качеств × число включённых звуковых дорожек. Затем результаты всех исходников суммируются. Видео без звука даёт один вариант на качество.

- 25 серий × 4 качества × 1 озвучка = **100 MP4**.
- Пример с несколькими озвучками: (20 серий × 3 озвучки + 5 серий × 2 озвучки) × 4 качества = **280 MP4**.

По умолчанию включены все найденные озвучки. Чтобы уменьшить число файлов, раскройте проект в очереди, выделите исходник нужной серии, откройте **Качество и звук** и снимите лишние озвучки. Выбор сохраняется для этого исходника. Качества папки выбираются в разделе **Источник**.

Профили выше разрешения исходника исключаются. Когда выбрано «Исходное разрешение», отдельный профиль с таким же разрешением не дублируется: например, для исходника 720p сочетание «Исходное + 720p + 480p + 360p» даёт три качества.

## Что изменилось

- До **1000 итоговых видео в одном импорте/черновике**: сканирование, расчёт подготовки, регистрация на сервере, редактирование и объединение файлов используют новый предел.
- Ограничение размера JSON повышено в клиенте и сервере, чтобы большой список файлов проходил целиком. Ограничение размера самого видео не менялось.
- Очередь показывает число **исходников** и число **итоговых MP4** отдельно.
- Дерево папки: **проект → исходник серии → качество → озвучка**. У исходника виден расчёт количества MP4.
- Статусы подготовки и число готовых MP4 обновляются во время работы, включая подготовку из раздела **Торренты**. После подготовки отдельно отображается создание черновика в WEB.
- Для исходного H.264/yuv420p показано **Копирование видео**; для остальных вариантов — **Кодирование**. Совместимый видеоряд сохраняется без повторного кодирования, уменьшенные качества обрабатываются отдельно.
- Обновление прогресса сохраняет раскрытые строки, выделение и прокрутку; для каждого процента дерево не пересоздаётся.
- После остановки активный вариант показывает «Пауза» с сохранением последнего этапа. Для смешанных S01/S02/S03 есть подсказка о нескольких сезонах, определённых по именам файлов.
- WEB получает все файлы открытого черновика одним запросом, даже если их нет среди последних 500 файлов библиотеки.

Текущий сезонный импорт направляет выбранные серии в указанный администратором сезон. Если исходная папка содержит S01, S02 и S03, это несколько сезонов: для такого импорта выбирайте серии одного сезона за раз и задавайте соответствующий номер. Новый лимит не меняет распределение по сезонам автоматически.

## Уже подготовленные задачи

Если набор качеств и озвучек вас устраивает, пересоздавать готовые файлы только ради нового лимита не требуется. Если меняете выбор:

1. Отметьте качества в **Источник**, при необходимости измените озвучки исходников через очередь.
2. В **Торренты** выделите скачанную задачу и нажмите **Переподготовить выбранную**.
3. После подготовки откройте задачу для отправки и проверьте новую WEB-карточку.
4. Запустите шаг 2, когда будете готовы оставить компьютер для отправки.

Повторное скачивание не требуется; исходники и прежние готовые копии сохраняются. При неизменных настройках готовые копии используются повторно. Изменение настроек может создать новый набор и новый черновик: оформление нужно проверить перед отправкой. Отправка и публикация автоматически не запускаются.

Сохранены предыдущие исправления ожидания подтверждения Telegram: неподтверждённая прежняя отправка проверяется до двух минут, свежая — до шести часов; автоматически повторно видео не отправляется.

## Проверка

На временных исходниках и SQLite в памяти проверены расчёты 100 и 280, разрешённый предел 1000 и отказ при превышении, сохранение исходников, работа статусов в настоящем окне Tk, полный импорт/редактирование/публикация 1000 файлов как 250 серий с четырьмя качествами. В изолированном браузере проверены открытие, обновление и сохранение карточки с 1000 файлами без запросов на каждый отдельный файл. Для проверки кодирования используются короткие синтетические видео FFmpeg. Реальная база и видео пользователя не изменялись, отправка в Telegram не выполнялась.
