# Заявки на сезоны, серии и озвучку

В карточке каталога появилась кнопка заявки. Она открывает тот же сценарий, что и поиск отсутствующего произведения. Для сериала пользователь подтверждает название в поиске, указывает сезон (0 — вышедшие сезоны), серию (0 — весь сезон) и озвучку. Можно выбрать любую озвучку, кнопку найденной озвучки или ввести название студии вручную, до 80 символов.

TMDB используется для проверки номеров, статуса сериала и дат выпуска. Завершение или отмена сериала само по себе не запрещает заявку на существующую серию. Отсутствующий сезон, отсутствующая серия, будущая дата или неизвестная дата выпуска серии не проходят автоматическую проверку. Полный сезон принимается, когда вышли все серии, перечисленные в TMDB. Сериал целиком означает известные вышедшие серии, без обещания добавлять будущие автоматически. Проверка повторяется перед отправкой заявки.

Если TMDB недоступен, ключ не настроен или название введено вручную, заявка принимается с отметкой о необходимости ручной проверки. Это не считается подтверждением существования или выпуска серии. Администратору следует проверить состав сезона перед подтверждением: при отсутствии внешних данных программа может проверить только имеющиеся файлы и их подписи.

Каждое сочетание произведения, сезона, серии и озвучки получает отдельную заявку. Регистр и лишние пробелы в названии студии не создают новую заявку, повторный голос одного пользователя не увеличивает счётчик. Старые заявки и их голоса сохраняются миграцией при обычном запуске сервера.

В Telegram-админке и веб-панели видны серия, студия и результат проверки. Для проверенного полного сезона закрытие заявки требует всех ожидаемых серий; для конкретной серии — её файла; для указанной студии — соответствующего варианта озвучки. Одна серия или другая озвучка не закрывают такую заявку. Для старых заявок без данных о составе сезона администратор подтверждает полноту вручную. Уведомления содержат параметры заявки.

## Кнопки озвучек Kinobox

По выбранному пользователем TMDB ID бот получает IMDb ID в пространстве фильма или сериала. По IMDb ID выполняется запрос Kinobox `/api/players`. Поиск по одному названию и неоднозначному числовому ID не используется. Если IMDb ID не найден, доступен ручной ввод.

Из успешных ответов источников берутся названия и ID озвучек. Одинаковые названия объединяются без учёта регистра и лишних пробелов; сведения об источниках сохраняются. Субтитры исключаются. В списке до 100 вариантов, по 10 кнопок на странице. Старые кнопки другого диалога выбора не применяются к новой заявке.

При выборе кнопки в заявке сохраняются источник, ID озвучки и время запроса в UTC. Эти сведения видны при подтверждении заявки, в Telegram-админке и веб-панели. Ручной ввод сам по себе не получает отметку источника. У общей заявки могут сохраниться сведения от предыдущих пользователей, выбравших эту озвучку через API.

Наличие озвучки у произведения не означает, что она доступна для всех сезонов и серий. Бот явно сообщает об этом; администратору нужно отдельно проверить нужные серии. Данные агрегатора не выдаются за подтверждение авторства непосредственно студией.

Кэш положительных и пустых ответов — час, ошибок и отсутствующих соответствий — минута, до 256 произведений в памяти. Между запросами Kinobox выдерживается минимум 0,55 секунды. Ответ ограничен 256 КиБ, сетевой таймаут — 7 секунд. При ошибках, неверном формате, двоичных ответах и слишком большом ответе остаётся ручной ввод. Плееры и медиа не скачиваются.

Переменные окружения:

| Переменная | Значение по умолчанию | Назначение |
|---|---|---|
| `TMDB_API_KEY` | нет | Поиск произведения и получение IMDb ID |
| `KINOBOX_ENABLED` | `1` | `0` отключает получение кнопок из API |
| `KINOBOX_API_URL` | `https://kinobox.tv/api/players` | Адрес совместимого API; меняйте только при необходимости |

Отдельный ключ Kinobox в описанном интерфейсе не используется. `.env` сам по себе не загружается: переменные нужно передать процессу бота или контейнеру.

Документация источников: [Kinobox API](https://kinobox.tv/api), [TMDB External IDs для сериалов](https://developer.themoviedb.org/reference/tv-series-external-ids).

Проверка доступности на сервере без запуска Telegram и работы с базой:

```sh
python tools/check_request_voices.py --imdb tt0903747
```

Код завершения 0 означает корректный ответ (список может быть пустым), 1 — источник недоступен или ответ не соответствует контракту. Сведения о доступности конкретной серии эта проверка не подтверждает.

Проверки выполнены на тестовой базе, с подменёнными ответами TMDB и Telegram и локальным HTTP-сервером вместо Kinobox. При живой проверке 25.10.2026 из среды разработки адрес Kinobox вернул двоичные данные вместо JSON. Живая выдача озвучек не подтверждена; автоматические кнопки появятся только при корректном ответе с сервера, ручной ввод работает независимо. Рабочий бот и рабочая база при разработке не запускались.
