# KinoTime Clips — первая локальная версия

Отдельная программа Windows. Не запускает Telegram-бота, не читает его токен и не меняет базу.
Фильмы выбираются исключительно вручную. Платные API, автоматические публикации и облачная
обработка не используются. Для установки библиотек и первоначального скачивания модели нужен интернет.

## Установка и запуск

Из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m pip install -r tools/clips_requirements.txt
.\.venv\Scripts\python.exe tools/download_clips_model.py
```

Второй шаг необязателен, если есть SRT. По умолчанию скачивается large-v3-turbo
из mobiuslabsgmbh/faster-whisper-large-v3-turbo (репозиторий из каталога faster-whisper).
Она крупнее прежней base и требует больше памяти; скорость зависит от компьютера.
Другие варианты загрузки: `--model base` или `--model medium`.
Программа обработки сама ничего не скачивает и использует модель на CPU в INT8.

Запуск: двойной щелчок по `tools/Start-KinoTime-Clips.cmd`.

1. Выберите фильм на диске.
2. Укажите SRT в UTF-8, совпадающий с монтажом и озвучкой фильма. Если SRT нет,
   выберите папку `runtime/clips/models/whisper-large-v3-turbo` после скачивания модели.
   Язык `ru` предназначен для русской речи, `auto` — для автоматического определения.
   Выберите нужную озвучку: она используется и для распознавания, и в готовом видео.
   Если путь фильма введён вручную, нажмите «Обновить дорожки».
3. Выберите папку результатов, подпись и призыв перейти в бота.
   Для рекламной полоски можно указать GIF, MP4, WebM или MOV. Она повторяется
   в верхней части ролика с отступом 140 пикселей на всём его протяжении. При её использовании надпись
   сверху и финальный текстовый призыв отключаются: призыв уже внутри баннера.
   Готовый пример: `dist/KinoTime-banner-profile.mp4`.
   Он использует аватарку `assets/kinotime-avatar.png` и голубые цвета KinoTime.
   Чтобы пересоздать баннер после правок дизайна, запустите
   `.\.venv\Scripts\python.exe tools/build_kinotime_banner.py`.
4. Установите диапазон длительности и нажмите «Найти фрагменты».
5. Выберите сцены (Ctrl/Shift для нескольких). При необходимости измените начало и конец
   в секундах и нажмите «Сохранить границы». Изменения границ не применяются до этой кнопки.
6. Стиль «По примеру» выбран по умолчанию: размытый видеофон, широкий кадр, короткие крупные
   субтитры под ним и баннер над ним. «Править субтитры» позволяет изменить время,
   текст и выделяемое зелёным/жёлтым слово, добавить или удалить строку.
   Исправления сохраняются в проекте. Если исходные субтитры SRT, программа оценивает
   время отдельных слов приблизительно; проверьте синхронизацию перед публикацией.
7. Нажмите «Смонтировать выбранные». Результат: MP4 720×1280, H.264/AAC, 30 кадров/с.
8. «Открыть готовое видео» откроет последний экспорт в системном плеере.
   Остальные видео доступны через «Папка результатов».

По умолчанию весь исходный кадр помещается на размытый фон. Центральное обрезание —
отдельный переключатель; отслеживания лиц пока нет. Субтитры вшиты в видео,
призыв появляется на последних семи секундах. Используется первая звуковая дорожка.
Если озвучка нужна другая, сначала подготовьте исходник с нужной дорожкой.
Баннер не создаёт отдельной заставки и не добавляет свою звуковую дорожку.

Сохраняются проект JSON (реплики, границы и оценки), ASS и JSON рядом с каждым MP4.
Проект можно открыть повторно без распознавания речи. Исходник должен остаться на том же пути.
Расшифровки кэшируются по пути, размеру, времени изменения фильма и папке модели.
Модели не следует заменять под тем же именем без очистки соответствующего кэша.
Файлы проекта и расшифровки содержат текст фильма и локальные пути — храните их локально.

## Что умеет и чего пока нет

Это прототип автоматического монтажа с предварительным отбором по речи, а не законченный
аналог Vizard. Рейтинг — прозрачная эвристика: вопрос в начале, ключевые слова,
темп речи, паузы и завершённость реплики. Сцены в последних 20% фильма получают штраф.
Это НЕ проверка спойлеров, НЕ оценка платформами и НЕ прогноз просмотров.

Пока нет смыслового анализа локальной языковой моделью, анализа действий и эмоций в кадре,
определения монтажных склеек, трекинга лиц, подключения
к каталогу и аналитики переходов. Поэтому немые сцены не отбираются, смысл и точность
субтитров проверяет человек. Не гарантируются 10–20 подходящих роликов на каждый фильм.

Отмена экспорта останавливает FFmpeg и удаляет незавершённый MP4. При распознавании отмена
проверяется между сегментами: загрузка модели или текущий сегмент могут задержать её.
Уже завершённые ролики сохраняются. Не закрывайте окно принудительно во время обработки.
Место на диске проверяйте до запуска; при ошибке готовые файлы сохраняются, частичный MP4 удаляется.

## Проверки

### Улучшение распознавания готовой сцены

Откройте старый проект, выберите модель large-v3-turbo, язык и нужную аудиодорожку.
Выделите одну сцену и нажмите «Распознать сцену заново». Программа обработает только
этот участок, обновит его субтитры и сохранит предыдущую версию проекта в файле
`before-recognition`. Затем проверьте текст и выполните повторный монтаж.
Новый поиск сцен для этого не нужен. Повторное распознавание игнорирует старый кэш.
Ошибки в именах, перекрывающейся речи и шумных сценах всё ещё возможны.

### Повторный экспорт после правки субтитров

Выбранный SRT перечитывается перед монтажом и открытием редактора. Если файл изменён
или выбран другой, субтитры проекта обновляются без повторного поиска сцен.
Таймкоды SRT должны отсчитываться от начала исходного фильма.
Старые ручные правки при замене SRT сохраняются в отдельной копии проекта
`project_….before-srt-….json`; новый SRT становится источником текста.
Если SRT не изменился, ручные правки сохраняются и имеют приоритет.

В редакторе «Сохранить субтитры» сохраняет и текущую редактируемую строку,
даже без отдельного нажатия «Применить к строке». Ручной текст и время работают
в обоих стилях; цветовые акценты — в стиле «По примеру».
После сохранения нужно снова нажать «Смонтировать выбранные» и открыть новый MP4.

```powershell
.\.venv\Scripts\python.exe -m unittest tests.test_local_clips -v
```

Проверяются разбор SRT, непересекающийся отбор, временные метки субтитров, безопасная
обработка ASS, настоящий экспорт с аудио/без аудио, оба режима кадра и отмена.
Скорость и качество отбора на полном художественном фильме требуют отдельного прогона.
