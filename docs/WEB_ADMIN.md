# Веб-панель: инструкция администратора

Сначала владелец сервера должен [включить панель](WEB_SETUP.md).
Доступ предоставляется администраторам из `ADMIN` в `data/config.py`.
Пользовательская роль с освобождением от подписки не даёт права администратора.

## Вход

Отправьте `/web` в личный чат с ботом и откройте кнопку «Открыть веб-панель».
Ссылка одноразовая и действует 10 минут, сессия — 12 часов. При истечении срока
получите новую ссылку. Не передавайте её другим людям. Для локального адреса
открывайте ссылку на компьютере с работающим ботом либо с SSH-туннелем к серверу.

## Новый сериал или фильм

1. В разделе «Загрузка» нажмите «Новый черновик».
2. Выберите тип контента, введите название. Для сериала укажите номер и название
   сезона. При желании заполните описание и HTTPS-ссылку на постер.
3. Перетащите файлы в окно или нажмите «Выбрать файлы». Для сериала можно выбрать
   несколько серий сразу; для фильма нужен один основной файл.
4. Отредактируйте названия в строках и проверьте порядок серий. Эти названия
   станут кнопками в боте. Порядок меняется стрелками.
5. Нажмите «Сохранить черновик» после редактирования. Передача идёт сначала
   с компьютера на сервер, затем с сервера в Telegram. Файлы поступают в ваш
   личный чат с ботом. Не закрывайте вкладку во время передачи с компьютера.
6. Дождитесь статуса «Готов» у всех файлов, нажмите «Опубликовать в боте»
   и подтвердите публикацию. До этого файлы не добавляются в каталог.
7. Откройте полученный код в боте и проверьте карточку, сезон и выдачу файлов.

При подключённом локальном Bot API лимит веб-загрузки — 2000 МБ на файл
(2 000 000 000 байт). Панель показывает действующий лимит; при облачном API
это 50 МБ. Файл, обозначенный ОС как «2 ГиБ», может превышать лимит 2000 МБ.

## Добавление серий в существующий сериал

Откройте «Каталог», найдите и выберите сериал. В форме выберите существующий
сезон либо создание нового сезона и укажите его номер. Затем добавьте файлы,
проверьте названия, сохраните и опубликуйте. Не создавайте заново сериал с тем же
названием, если хотите дополнить существующий: это будет отдельная карточка.

## Файлы до 4 ГБ через Telegram Desktop

1. Откройте **того же бота** в Telegram Desktop с Premium-аккаунта администратора.
2. Отправьте `/webfiles`.
3. Прикрепите видео или документ. Можно отправить несколько файлов подряд.
   Дождитесь подтверждения бота «Файл добавлен в „Из Telegram“» для каждого файла.
4. Отправьте `/done`, затем откройте `/web`.
5. Подготовьте черновик с названием фильма или сериала. В разделе «Из Telegram»
   нажмите «Обновить», отметьте файлы и «Добавить выбранные в черновик».
6. Проверьте названия и порядок, затем опубликуйте.

Бот сохраняет идентификатор уже полученного файла: повторная загрузка через
браузер не нужна. Файл должен быть получен этим ботом от вашего аккаунта;
идентификатор файла другого бота не подходит. Новую загрузку до 4 ГБ выполняет
Premium-клиент Telegram. Возможность отправки больших файлов описана в
[Telegram Premium FAQ](https://telegram.org/faq_premium#q-what-are-the-benefits-of-telegram-premium).
Полный сценарий с реальным файлом такого размера ещё нужно проверить на сервере.

## Продолжение работы и ошибки

- Сохранённая публикация доступна в списке «Продолжить черновик».
- Если прервалась передача из браузера, откройте черновик и выберите тот же
  неизменённый файл повторно. Для незавершённой загрузки панель продолжит передачу.
- Если произошла ошибка отправки в Telegram, используйте «Повторить».
  После аварии сначала проверьте чат: Telegram мог уже принять файл. В таком
  случае его можно переслать боту в режиме `/webfiles` и выбрать в «Из Telegram».
- Удаление незавершённой загрузки через панель освобождает её временное место.
  Удаление готового файла из черновика не удаляет его из Telegram или уже
  опубликованного каталога.
- Опубликованный черновик закрывается для редактирования. Для следующих серий
  создайте новый черновик и выберите сериал через «Каталог».
- Черновики и полученные файлы принадлежат вошедшему администратору. Если файл
  не виден, проверьте, что в Telegram и панели используется тот же аккаунт.
