# KinoTime 1.3.0: несколько компьютеров

Обновление подготовлено для существующей версии бота с конкурсами, качествами серий и импортом до 1000 файлов. Обновляются сервер и все лаунчеры, работающие с ним. Видео по-прежнему отправляются через Telegram Desktop, а публикация остаётся после проверки в веб-панели.

## Порядок установки

1. Остановите очереди во всех лаунчерах. Дождитесь окончания начатых загрузок в Telegram. Сохраните резервную копию рабочей базы средствами панели.
2. На хостинге остановите бота. Из `KinoTime-Server-MultiPC-1.3.0.zip` перенесите содержимое папки `Server` в корень проекта с заменой только перечисленных файлов. Не заменяйте каталог `database` целиком: в архиве из него есть только `migrations.py`. Не загружайте старую базу из исходников проекта.
3. Полностью перезапустите бота. При запуске миграция 19 расширяет существующую базу; перед изменением создаётся резервная копия в настроенном `BACKUP_DIR`. Каталог, пользователи, прогресс просмотров, конкурсы и принятые файлы сохраняются. `DATABASE_PATH`, `DATA_DIR` и настройки постоянного диска не меняйте.
4. Обновите лаунчеры установщиком `KinoTime-Setup-1.3.0.exe` либо замените самостоятельный `KinoTime.exe`. На сервер EXE загружать не нужно. Закройте старые окна перед обновлением.
5. На каждом ПК получите **свой новый код** командой `/desktop`. В «Настройках» укажите адрес, код и понятное имя компьютера. Нажмите «Сохранить настройки» и «Проверить связь». Один код привязывается к одному ПК и действует 48 часов; он не записывается на диск.
6. Обновите страницу веб-панели (Ctrl+F5). В разделе «Лаунчер» выберите компьютер. Его папки, качества, состояние и история команд показываются отдельно. Команды подготовки, отправки и остановки адресованы выбранному ПК.

## Продолжение старой очереди

При обновлении существующего EXE установщик сохраняет настройки и идентификатор ПК. Исходники, готовые MP4 и журналы очереди не удаляются.

Если переходите с Python-лаунчера на EXE **на том же компьютере**, в «Настройках» нажмите «Перенести настройки старого лаунчера» и выберите его `tools/launcher-settings.json`. Затем получите свежий код `/desktop`. Это позволяет продолжить старый импорт с прежними идентификаторами файлов. Старый лаунчер при этом должен быть закрыт.

Не копируйте старые настройки и журналы на второй ПК для одновременной работы. Установите там чистую программу, получите отдельный код и выберите его локальные папки. Черновики, существовавшие до обновления, привязываются к последнему зарегистрированному старому лаунчеру; черновики без владельца принимаются первым импортом с совпадающим составом файлов. Если импорт принадлежит другому компьютеру, продолжайте его на этом компьютере.

## Отправка и повторы

Для каждого готового файла рассчитывается полная SHA-256. Это добавляет одно чтение диска перед первым импортом; контрольная сумма неизменённого файла берётся из локального кэша. Она проверяет точное совпадение содержимого, а не похожесть названия.

Два компьютера одного администратора не могут одновременно отправлять одинаковый зарегистрированный файл. Если он уже принят ботом, второй черновик получает сохранённый Telegram `file_id` без новой загрузки. Разные кодировки одного фильма могут иметь разные байты и не объединяются автоматически. Старые файлы без контрольной суммы защищаются по зарегистрированной метке файла.

Перед отправкой сервер выдаёт временное разрешение и продлевает его при связи с лаунчером. Прямо перед нажатием «Отправить» отмечается начало передачи. Эта отметка сохраняется при обрыве сети и перезапуске. Она не исчезает автоматически, поскольку загрузка в Telegram могла продолжиться.

Если загрузка отменена или файл точно не отправлялся, на исходном ПК нажмите «Разрешить безопасный повтор» и подтвердите отсутствие отправки и загрузки. Сброс затрагивает только передачи этого компьютера. Если видео ещё загружается, дождитесь окончания. Подтверждённые файлы повторно не отправляются.

## Ограничения и проверка

На одном профиле Windows работает одно окно лаунчера. Каждый ПК готовит свои файлы независимо. Для отправки нужны открытый Telegram Desktop, аккаунт администратора и разблокированный компьютер. Лимит одного импорта — 1000 вариантов MP4. Установка программы включает Python/FFmpeg/FFprobe; qBittorrent и Telegram Desktop устанавливаются отдельно.

Проверки выполнялись на временных базах и синтетических видео: два ПК под одним администратором, адресация команд, отдельные черновики, защита повторов, повторное использование файла и сохранность данных при миграции. Сервер на BotHost не обновлялся автоматически; реальная отправка в Telegram не запускалась.
