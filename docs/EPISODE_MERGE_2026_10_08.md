# Объединение серий — 8 октября 2026

## Установка

Остановите бот, скопируйте файлы из `Server` архива поверх соответствующих
исходников проекта с сохранением путей, затем запустите бот и обновите
страницу веб-панели. В архиве нет пользовательской базы и медиа.
Не заменяйте папку `database` целиком: файл `database/episode_variants.py`
является исходником Python. Структура базы данных не меняется.

Обновление применяется к текущей версии проекта с качествами и озвучками
серий. Также включено предыдущее исправление навигации: сезон → серия →
качество → озвучка, переходы с сохранением параметров и отправленных видео.
Обновлять установленный лаунчер для этой функции не требуется.

## Пример: опечатка разделила вторую серию

1. Откройте «Каталог» → «Папки и файлы» → нужный сезон.
2. Отметьте флажками обе записи второй серии. Можно выбрать больше двух
   записей, но все должны принадлежать одному сезону.
3. В блоке «Объединить серии» выберите основную запись: её ID сохранится.
4. Укажите правильное итоговое название в отдельном поле объединения.
5. Нажмите «Проверить объединение». Проверка не изменяет каталог.
6. Проверьте название, основную запись, число вариантов и возможные конфликты.
   Нажмите «Объединить серии», если результат подходит.

Если раньше меняли обычные поля названий папок или серий, сначала сохраните
эти изменения. Итоговое имя объединённой серии можно задать в блоке
объединения, сохранив разные имена исходных записей до проверки.

## Что сохраняется

Все различные пары «качество + озвучка» попадут в одну серию. Их Telegram-файлы,
Storage-ссылки и ID вариантов сохраняются. Для точных дублей одного варианта
остаётся одна запись. Все отметки просмотра выбранных серий объединяются;
для каждого пользователя сохраняется наиболее ранняя дата просмотра.
Название карточки, другие серии и другие сезоны остаются в каталоге.

Перезагружать видео не нужно. Выбранная основная серия сохраняет ID.
Удалённые дополнительные записи исчезнут из списка серий, поэтому старые
кнопки этих записей нужно открыть заново через список серий. Ранее отправленные
видео остаются в чате.

## Конфликты

Если у разных файлов одинаковые качество и озвучка, инструмент покажет
названия конфликтующих серий и остановит объединение. Он не выбирает файл
автоматически и не заменяет другой вариант. Аналогично блокируется объединение
двух различных старых исходных файлов без сведений о качестве и озвучке.

Если итоговое имя уже принадлежит другой записи этого сезона, включите её в
выбор либо укажите другое название. Если после проверки данные изменились,
повторите проверку. Объединение выполняется в одной транзакции: при ошибке
весь каталог и отметки остаются в прежнем состоянии.

## Проверка

Тесты используют базу в памяти и локальный HTTP-сервер. Браузерная проверка
использует подменённые API-ответы и проверяет интерфейс на компьютере и телефоне.
Результаты включены в `Verification` архива. Продукционная база, публикации и
Telegram-сообщения при проверках не использовались.
