# Импорт через Telegram Desktop

Видео отправляет **Telegram Desktop на компьютере с фильмами**, с уже
авторизованного аккаунта администратора. Лаунчер не использует Bot API для
загрузки видео и не читает Telegram-сессию. В режиме импорта папки
используются уже скачанные фильмы; раздел «Торренты» управляет скачиванием через qBittorrent.
Через HTTPS передаются только список файлов и запросы готовности.

Для скачивания `.torrent` и magnet через новую очередь лаунчера см.
[Торрент-очередь](TORRENT_LAUNCHER.md). Она управляет отдельным локальным
qBittorrent; подготовка и ручная отправка используют прежний механизм.

## Тихая подготовка и отправка позже

В разделе «Очередь» включите «Тихая подготовка» и нажмите
«1. Подготовить без отправки». Лаунчер свернётся на панель задач Windows,
а подготовка MP4 и создание черновиков продолжатся без открытия Telegram.
Завершение подготовки не запускает отправку автоматически.
Чтобы проверить прогресс или остановить задачу, разверните окно с панели задач.
Не закрывайте лаунчер; сон компьютера прерывает выполнение.

Когда будете готовы оставить компьютер, разверните лаунчер, проверьте карточки,
выключите «Тихая подготовка» и запустите шаг 2 в разделе «Telegram».
Пока переключатель включён, отправка заблокирована также для удалённых команд.
Переключатель не прерывает отправку, которая уже началась: для этого нажмите «Стоп».
Тихая подготовка скрывает рабочее окно, но обработка видео продолжает потреблять ресурсы.

## Установка и запуск

На сервере обновите код и перезапустите бот. При обычном запуске применяется
миграция БД с резервной копией. Включённая веб-панель должна быть доступна с
компьютера с фильмами по HTTPS. Локальный адрес панели сервера на другом
компьютере не подойдёт.

На компьютере с фильмами нужны Windows, Python 3.11 и Telegram Desktop:

```powershell
py -3.11 -m pip install -r tools/desktop-requirements.txt
py -3.11 tools/desktop_launcher.py
```

Также установите FFmpeg: команды `ffmpeg` и `ffprobe` должны быть доступны в PATH.
Лаунчер проверяет реальный контейнер и кодеки: переименование AVI в `.mp4`
не делает его совместимым видео. Для несовместимых файлов он готовит отдельную
копию MP4 (H.264, yuv420p, AAC) в папке `KinoTime-Ready` рядом с исходной папкой фильма, с сохранением
подпапок. Это требует дополнительного места и времени; преобразование видео
может немного изменить качество. Исходники остаются на месте. Сохраняются
аудиодорожки, встроенные субтитры в копию не переносятся. Для нужных субтитров
подготовьте видео отдельно. Готовые копии используются повторно; незавершённые
копии не отправляются. Кнопка «Стоп» останавливает и преобразование.

1. Отправьте боту `/desktop` с аккаунта администратора.
2. Введите в лаунчере адрес панели и полученный код. Новый код действует 48 часов;
   он разрешает импорт и чтение готовности, но не одобрение или публикацию.
3. Выберите папку **одного фильма** и нажмите «Подготовить MP4 и карточку».
   Дождитесь подготовки. В `/web` проверьте тип, название/год для TMDB,
   категории и названия вариантов (подкатегорий), сохраните черновик.
   Лаунчер использует отдельный импорт вместо нажатий в мастере `/admin`:
   после одобрения создаются обычные записи каталога и категорий того же бота.
4. Нажмите «Отправить через Telegram Desktop». Лаунчер откроет бота по его
   имени, полученному от сервера. Проверьте получателя в течение обратного отсчёта.
5. Лаунчер прикрепляет файлы по одному **как видео с плеером**, проверяет,
   что «Send as a document / Отправить как документ» выключено,
   заполняет служебную подпись и нажимает
   «Отправить». Следующий файл отправляется только после подтверждения сервера.
6. Откройте `/web`, выберите созданный черновик. Проверьте варианты, описание
   и постер. При единственном точном совпадении названия (и года в скобках, если
   он указан) описание и постер подставляются автоматически из TMDB.
   «Подобрать описание и постер» использует существующее подключение
   TMDB: выберите правильный фильм из результатов. Без ключа TMDB доступна
   базовая карточка по названию папки и ручное редактирование.
   Отдельная языковая модель для переработки текста по комментариям пока не
   подключена: комментарии сохраняются, исправления вносятся в редакторе карточки.
7. Нажмите «Одобрить и опубликовать», «Отклонить» или «На доработку» с комментарием.
   После исправления верните черновик на проверку. История решений сохраняется.
8. После публикации нажмите «Подготовить пост» и скопируйте текст в канал фильма.
   Пост содержит ссылку `https://t.me/<bot>?start=movie_<номер>`. Ссылка открывает
   фильм; при обязательной подписке бот сначала проверяет её. Лаунчер не публикует
   рекламные сообщения в каналы.

## Структура

### Массовая загрузка из общей папки

В массовом режиме **каждый файл непосредственно в общей папке — отдельный фильм**.
Подпапки не обходятся. Например:

```text
Фильмы/
  Лёд (2018).mp4
  Другой фильм (2024).mkv
```

1. После обновления сервера получите свежий `/desktop`. Старые коды сохраняют
   прежний срок действия. Введите адрес и код, выберите общую папку.
2. Нажмите «Показать очередь». Проверьте названия: они извлекаются из имён файлов.
   Используйте «Название (год)», чтобы упростить поиск TMDB. Разные версии одного
   фильма в массовом режиме будут разными карточками; для вариантов используйте
   обычный импорт папки одного фильма.
3. Нажмите «Запустить / продолжить очередь». Лаунчер сначала проверит поддержку
   очереди сервером, затем последовательно подготовит и отправит фильмы. Он
   создаёт черновики, но не имеет права их публиковать. TMDB заполняет карточку
   только при единственном точном совпадении; остальные проверяются вручную.
4. После возвращения откройте `/web` → «Пакетная проверка». Проверьте карточки,
   отметьте готовые и нажмите «Одобрить выбранные». На странице до 20 карточек;
   есть переход между страницами. Выбор относится к текущей странице.

Локальный журнал `.kinotime-batch.json` сохраняет состояние без кода доступа.
Повторный запуск пропускает готовые фильмы в той же панели и для того же
администратора. Нельзя одновременно запустить одну очередь в двух лаунчерах.
Ошибка преобразования одного фильма не мешает остальным. При временной потере
связи запросы повторяются с паузами до примерно двух часов. При истёкшем коде,
потере доступа к окну Telegram или неизвестном результате отправки очередь
приостанавливается. Повторная отправка без подтверждения автоматически запрещена.

Для работы на 10+ часов оставьте компьютер включённым, подключённым к питанию
и интернету, **Windows разблокированной, а Telegram — открытым**. Не пользуйтесь
Telegram одновременно с очередью. На время работы лаунчер временно предотвращает
обычный сон и выключение дисплея; после остановки запрос снимается. Он не отключает
блокировку Windows, не меняет политики безопасности и не обходит экран входа.
Перезапуск системы требует повторного запуска лаунчера и ввода кода. Это очередь
для открытого рабочего стола, а не фоновая служба на заблокированном компьютере.

Массовая публикация проверяет готовность каждого файла и права администратора.
Если карточка изменилась после просмотра, её нужно проверить заново. Ошибка одной
карточки не отменяет удачную публикацию остальных; повтор запроса не создаёт копий.

### Несколько вариантов одного фильма

```text
Название фильма/
  1080p/
    Дубляж/
      movie.mkv
  720p/
    Оригинал/
      movie.mkv
```

Первая подпапка становится категорией (1080p), остальные подпапки и имя файла —
названием варианта («Дубляж / movie»). Это соответствует двум уровням навигации
существующего бота. Полный исходный путь сохраняется в БД, относительный путь
виден в черновике. Произвольная глубина папок сохраняется в подписи варианта,
но не создаёт дополнительные уровни меню. Поддерживается до 200 видео на фильм.
Файлы с одинаковыми именами связываются по уникальной метке в подписи.

## Остановка и повтор

Не переключайте чат и не вводите текст во время подготовки вложения.
Кнопка «Стоп» прекращает дальнейшие операции; уже начатую загрузку отменяйте
в Telegram самостоятельно. Закрытие лаунчера также не отменяет передачу в Desktop.

Лаунчер сохраняет `.kinotime-transfer.json` рядом с фильмом, без кода доступа.
Повторный запуск проверяет подтверждения сервера и пропускает принятые файлы.
Если неизвестно, было ли нажатие «Отправить» успешным, повторной отправки
автоматически не будет. Проверьте Telegram. Только если файл не отправляется
и не был отправлен, используйте «Разрешить повтор после проверки Telegram».
Исходные видео не удаляются и не перемещаются. Не меняйте их после сканирования.
Для нового состава фильма используйте новую папку; повтор того же импорта
не создаёт вторую карточку.

Подготовленная MP4-копия находится в другой папке и имеет отдельный черновик.
Если до обновления уже создавался черновик исходного несовместимого файла,
он остаётся в админке; его можно отклонить, чтобы не путать с новой карточкой.

## Совместимость и проверка перед использованием

Автоматизация зависит от элементов доступности установленной версии Telegram
Desktop (русский или английский интерфейс). Она проверяет процесс Telegram,
заголовок чата, поле подписи и кнопку отправки. Если элементы недоступны, она
останавливается без слепых кликов по координатам. На конкретном компьютере
**нужно проверить первый импорт на небольшом тестовом видео**. Автоматические
тесты проекта проверяют протокол и состояние, но не заменяют проверку Desktop.

Если лаунчер не распознаёт заголовок уже открытого чата, сначала выполните
«Подготовить MP4 и карточку», затем «Проверить совместимость Telegram
(без отправки)». Оставьте окно Telegram на переднем плане на 8 секунд.
Результат сохранится в `tools/desktop-diagnostics.json` рядом с лаунчером.
Этот файл содержит только сводку типов и количества элементов интерфейса,
размер окна и результат сравнения заголовка. Переписка, имена чатов и код
подключения в него не записываются. Передайте файл для проверки совместимости.

Telegram допускает файлы до 2 ГБ, с Premium — до 4 ГБ:
[официальный FAQ](https://telegram.org/faq#q-what-can-i-do-with-telegram).
Telegram Desktop должен отправить подготовленный MP4 без дополнительного изменения:
бот сверяет имя и размер именно этой копии. Если получен отказ, проверьте сообщение бота. Лимит 50 МБ веб-загрузки
к этому способу импорта не относится. Выдачу файла большого размера ботом
также проверьте в своей конфигурации на одном фильме перед массовым импортом.
