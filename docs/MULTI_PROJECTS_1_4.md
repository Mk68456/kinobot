# Несколько проектов в KinoTime 1.4.0

В одном окне можно готовить несколько фильмов или сериалов. Проекты имеют
отдельные настройки, прогресс, паузу и продолжение. По умолчанию работают
два проекта одновременно. В разделе «Проекты» доступны от одной до четырёх
одновременных обработок. Для изменения лимита сначала приостановите проекты.

## Как начать

1. В «Источнике» выберите папку и отметьте нужные качества.
2. Для сериала выберите «Один проект / сериал». Одна папка — один сезон.
   Для независимых фильмов в общей папке выберите режим нескольких фильмов:
   в этом случае каждый исходник получит отдельную WEB-карточку.
3. Если нужны конкретные озвучки, предварительно просканируйте очередь и
   настройте их в «Качестве и звуке». Рядом с дорожками показан язык из метаданных.
   Выберите язык в списке и нажмите «Выбрать только этот язык», затем при необходимости
   измените отдельные галочки и нажмите «Сохранить выбор». Дорожки без языка отмечены
   «Язык не указан»; проверьте их вручную. Неотмеченные дорожки не создают MP4.
   Выбор сохраняется для конкретного исходника. Без сохранённых настроек включены все дорожки.
4. Откройте «Проекты». Для импорта сезона существующего сериала заполните
   его номер в каталоге и номер сезона. Для обычного импорта оставьте поля пустыми.
   Номер сериала берётся из WEB-панели; лаунчер не создаёт новый сериал автоматически.
5. Нажмите «Добавить выбранный источник». Настройки фиксируются для этого проекта.
6. Выберите другую папку и добавьте следующий проект, пока первый рендерится.

В списке показаны проекты, готовые MP4 и текущий этап. Ниже раскрываются серии,
качества и озвучки выбранного проекта. «Пауза проекта» останавливает только его;
«Пауза всех» — все рендеры. Отправка останавливается кнопкой «Остановить» в
разделе Telegram. Удалённая команда остановки останавливает и проекты, и отправку.

Планировщик выдаёт каждому проекту очередь на одну серию в одном качестве
со всеми выбранными озвучками. Затем очередь получает следующий проект.
При одном месте обработки проекты чередуются; при двух или более обрабатываются
параллельно. Повышенный приоритет даёт проекту следующую свободную очередь;
уже выполняющийся рендер другого проекта не прерывается. Снова нажмите кнопку
приоритета, чтобы вернуть обычный порядок. У одного проекта одновременно
выполняется только одна такая часть обработки.

Видеоряд выбранного качества кодируется один раз и используется для всех
его озвучек. Общий выбранный бюджет потоков CPU делится между местами обработки.
Это не жёсткое ограничение загрузки CPU или GPU. Большее число обработок
не гарантирует ускорения: для начала используйте два места и сравните скорость.
При аппаратном сбое сохраняется существующий переход на CPU.

## Карточки и отправка

После состояния «MP4 готовы» выберите проект и нажмите «Создать карточки».
Нужны адрес панели и действующий код `/desktop` в настройках.
Оформите карточки в WEB, затем нажмите «Отправить» в «Проектах».
Telegram Desktop обслуживает один проект за раз; остальные могут продолжать рендер.
Лаунчер не публикует карточки автоматически. Обычная старая очередь и торрент-рендер
запускаются после паузы проектов, чтобы не обходить ограничения ресурсов.

Проект привязывается к панели и идентификатору компьютера при создании карточек.
Замена подключения не перенаправит незаметно готовые файлы другому серверу.
Идентификаторы карточек и файлов сохраняются до начала передачи. Повторная
отправка проверяет подтверждения бота и пропускает уже принятые файлы, даже если
подтверждённые локальные копии были очищены. Изменение состава карточки в WEB
останавливает передачу для проверки.

При неопределённом результате отправки она приостанавливается. Повторите её
через «Отправить»: действуют существующие журналы и защита от повторной отправки.
Если бот отклонил карточку, при новом запуске отправки используется существующее
восстановление отклонённой карточки. Опубликованная карточка повторно не отправляется.

## Сохранение и ограничения

Новые проекты хранятся в `launcher-projects.sqlite` рядом с настройками лаунчера.
В установленной версии это `%LOCALAPPDATA%\KinoTime\Launcher`.
Коды подключения и пароли в журнал не записываются.
Рендер работает локально без панели; создание карточек и отправка требуют подключения.
После закрытия незавершённые проекты восстанавливаются на паузе.
Нажмите «Продолжить». Уже завершённые части обработки повторно не запускаются.
Текущий незавершённый MP4 после остановки создаётся заново; полностью готовые
варианты внутри этой части подхватываются из кеша.

Исходники сохраняются. Готовые MP4 и кеш лежат рядом с исходной папкой, внутри
`KinoTime-Ready\project-<идентификатор>`. Не переносите и не удаляйте их во время работы.
Свободное место резервируется с учётом других активных обработок. При недостатке
места проект ожидает освобождения диска. В этом режиме файлы копятся до отдельной
отправки; это не потоковый режим «рендер → отправка → очистка».

Одинаковые исходники нельзя добавить во второй незавершённый проект. Для каждого
нового запуска используются отдельные каталоги кеша, чтобы разные проекты
не перезаписывали промежуточные файлы. Изменение исходника после планирования
останавливает соответствующую обработку с ошибкой.
Лимит одной WEB-карточки — 1000 итоговых MP4. Существующие очереди и их журналы
сохраняют прежний формат; новая очередь не подхватывает их задания автоматически.

Обновление сервера не нужно, если он уже поддерживает несколько компьютеров
и импорт сезонов. Управление отдельными проектами доступно в локальном окне;
веб-панель получает список их состояний, но прежние кнопки управляют компьютером
в целом. Неограниченная параллельная отправка через Telegram не включается.
