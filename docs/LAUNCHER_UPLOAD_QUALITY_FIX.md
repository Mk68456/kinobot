# Исправление ожидания отправки и качеств сезона

## Установка на компьютере

1. Остановите очередь и закройте лаунчер. Закрытие лаунчера само по себе не отменяет загрузку, которая уже идёт в Telegram Desktop.
2. В рабочей папке лаунчера замените три файла, сохраняя пути:
   - `tools/desktop_launcher.py`
   - `tools/torrent_queue.py`
   - `tools/torrent_panel.py`
3. Запустите лаунчер привычным способом.

Это обновление локального лаунчера. На сервер загружать его не нужно. База, конфигурация, коды подключения, видео и журналы очереди не включены в ZIP. Не удаляйте `.kinotime-batch.json`, `.kinotime-transfer.json`, настройки и готовые файлы.

Файлы в `tests/` нужны только для локальной проверки.

## Неподтверждённая отправка

- Лаунчер показывает количество файлов, принятых ботом, и время ожидания. Это подтверждения бота, а не проценты загрузки Telegram.
- Ранее отмеченный как отправленный файл при возобновлении проверяется до двух минут. Он не отправляется повторно автоматически.
- Если подтверждения нет, очередь ставится на паузу с объяснением. Маркер неподтверждённой отправки сохраняется.
- Для новой отправки сохраняется длительное ожидание до шести часов: большие файлы могут загружаться долго.
- Уже принятые сервером файлы пропускаются; запоздавшее подтверждение также учитывается.

Для ситуации «проверяю подтверждение предыдущей отправки»:

1. Проверьте состояние этого видео в Telegram Desktop.
2. Если загрузка продолжается, дождитесь окончания и снова запустите шаг 2. Автоматическая повторная отправка не нужна.
3. Если видео отсутствует или загрузка отменена, после остановки очереди нажмите **Разрешить безопасный повтор**, затем шаг 2.
4. Если видео уже полностью отправлено, но бот не подтвердил его, проверьте ответ бота и серверные логи. Не разрешайте повтор вслепую.

## Подготовка качеств

Выбранные в разделе **Источник** качества теперь применяются и к папке одного проекта, и к папке сезона из торрентов. Для каждой серии создаются отдельные варианты качества и озвучки; у всех вариантов сохраняется одно название серии. В веб-панели они поступают на проверку как варианты этой серии.

Для уже скачанной задачи:

1. В разделе **Источник** отметьте нужные качества.
2. Откройте **Торренты** и выделите задачу.
3. Нажмите **Переподготовить выбранную**.
4. Дождитесь окончания подготовки, нажмите **Открыть для отправки** и проверьте новую карточку в WEB-панели. Затем запустите шаг 2.

Повторного скачивания не происходит. Исходники, прежние готовые копии и прежние WEB-карточки сохраняются. Готовые варианты с теми же настройками используются повторно. Смена набора качеств создаёт отдельный набор файлов и может создать новую WEB-карточку; оформление проверьте перед отправкой. Уже опубликованный сезон повторным полным импортом не заменяется: для него дополнительные варианты добавляются через существующие инструменты WEB-панели.

Качество выше разрешения исходника не создаётся. Если выбран исходник 720p, отдельный 720p исключается как дублирующий вариант; 480p и 360p при достаточном разрешении всё равно готовятся. Для исходника 1080p сочетание «Исходное + 720p + 480p + 360p» даёт четыре качества. При слишком низком исходном разрешении остаются только подходящие варианты. Видео без звука также поддерживают явно выбранные качества.

До 200 файлов допускаются одним импортом. Несколько озвучек увеличивают количество файлов. Подготовка работает со скрытыми процессами FFmpeg; отправка в Telegram запускается отдельно вручную.

## Проверка

Проверены сценарии подготовки, возобновления, отмены, безопасного повтора, качества и озвучки, работа кнопки переподготовки и регистрация сезона в веб-панели. На реальных коротких видео FFmpeg созданы четыре качества для каждой из двух серий; после одобрения получены две серии с восемью вариантами качества. Тесты используют временные папки, SQLite в памяти и имитацию Telegram/API; реальная отправка пользовательских видео не выполнялась.
