# Проверка обязательных подписок при переходе из конкурса

Это исправление для установленного обновления реферальных конкурсов KinoTime.

## Что исправлено

- Кнопка «Открыть карточки каталога» проверяет обязательные каналы бота.
- Каждая карточка и каждая страница списка также проверяют подписки. Ранее отправленные кнопки используют новую проверку после перезапуска.
- Если подписок нет, бот показывает обязательные каналы и кнопку «Я подписался✅». Эта кнопка повторяет проверку и открывает ту же страницу или карточку.
- До успешного открытия карточки реферал остаётся неподтверждённым; один только переход на страницу конкурса не начисляет билет.
- Необязательный канал новостей конкурса не добавляется в список обязательных каналов. Список берётся из существующих настроек бота. Если администратор отдельно добавил этот канал в обязательные, бот проверит его как любой другой обязательный канал.
- Разрешённый обход подписок для пользовательских ролей сохраняется. Доступ по отдельной ссылке на фильм не открывает весь каталог конкурса.
- Ошибка Telegram при проверке подписки не открывает каталог. Пользователь получает сообщение с каналами, а причина остаётся в логах.

## Установка

1. Замените три файла, сохраняя пути из архива:
   - `handlers/users/contests.py`
   - `keyboards/inline/sub_keyboard.py`
   - `services/contests.py`
2. Перезапустите бота.
3. Пользователем без подписки нажмите «Открыть карточки каталога»: должны появиться обязательные каналы. Подпишитесь, нажмите «Я подписался✅» и проверьте, что открывается каталог.

`tests/test_handlers.py` — только для локальной проверки, устанавливать на сервер не обязательно.

В архиве нет SQLite, конфигурации, токенов или медиа. Миграция базы не требуется. Рабочий `DATABASE_PATH` и постоянное хранилище должны остаться прежними. Запущенный конкурс, его ссылки и накопленные данные сохраняются; заново создавать или запускать конкурс не нужно. Ранее начисленные билеты не пересчитываются этим исправлением.

Если хостинг заменяет весь контейнер при загрузке архива, обновляйте исходные файлы внутри актуального проекта и используйте предусмотренное хостингом постоянное хранилище базы. Этот ZIP является дополнением к установленному проекту, а не полным проектом для развёртывания.
