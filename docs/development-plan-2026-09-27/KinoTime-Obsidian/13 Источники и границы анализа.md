# Источники и границы анализа

## Метод

Изучены структура, README и ключевые документы, запуск, настройки путей, соединение и миграции БД, поиск, статистика, доступ и ссылки, авторизация WEB, импорт, Storage, развёртывание и тесты. Это обзор архитектуры и готовности продукта, а не построчный аудит каждого файла, пентест или проверка production.

В проекте не найден AGENTS.md при поиске по рабочему дереву. Чаты получены через доступные задачи Codex с тем же рабочим каталогом/projectId. Отдельных файлов-экспортов чатов в просмотренном списке исходников не обнаружено. История больших задач прочитана выборочно через доступные страницы; архивные задачи и недоступные сообщения не считаются просмотренными. У части последних ходов задачи импорта инструмент вернул пустые items, поэтому их содержание не восстанавливалось по догадке.

## Основные локальные доказательства

- README.md — текущие пользовательские возможности, хранение, тесты и ограничения.
- docs/CURRENT_UPDATE.md — история архивных выпусков; местами отстаёт от более новых изменений.
- docs/DESKTOP_IMPORT.md — реальная зависимость от открытого Desktop и разблокированного компьютера.
- pyproject.toml, uv.lock, .github/workflows — закрепление зависимостей и конфигурация проверок; workflow-файл не доказывает, что удалённый CI сейчас работает.
- database/migrations.py — 16 миграций, разделы, заявки, Storage, WEB и управление лаунчером.
- database/connection.py и database/search.py — синхронная SQLite, WAL и поиск в Python.
- database/stats.py и handlers/users/find_movie.py — различие открытий карточек и реального потребления видео.
- handlers/start.py и services/movie_sharing.py — существующие movie_/share_ входы и ограниченный доступ.
- webpanel/auth.py и webpanel/server.py — одноразовые ссылки, сессии, Origin/CSRF.
- services/storage_backup.py — очередь копирования, ссылки на сообщения, copy_message и fallback.
- tools/desktop_launcher.py — существующие профили source/1080p/720p/480p/360p, выбор озвучек.
- compose.yaml и data/settings.py — тома, пути, WEB и текущие healthcheck.

Для удобного открытия файлов исходного проекта в исходном расположении используйте карту «14 Файлы проекта». Хранилище переносимо; внешние абсолютные ссылки после переноса компьютера могут требовать изменения.

## Проверки 27.09.2026

`python -m unittest discover -s tests` из проектного окружения: **161 тест, OK**, 18,338 секунды по выводу процесса. Сообщения об ошибках подписки и Storage появились в намеренно моделируемых отрицательных сценариях; итог набора успешный.

`ruff check .`: **18 замечаний**, найденных в исторических копиях dist. Проверка `app.py loader.py data database handlers keyboards services states tests tools utils webpanel`: **All checks passed**. Рабочий код в рамках этой задачи не исправлялся.

Автоматические проверки не выполняли реальную отправку Telegram, воспроизведение на телефоне, проверку каналов, применение миграций к production или измерение живой аудитории.
