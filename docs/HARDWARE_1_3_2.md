# KinoTime Launcher 1.3.2 — выбор оборудования

В «Очереди» появился переключатель «Кодирование»: автоматически, NVIDIA NVENC,
Intel Quick Sync, AMD AMF или процессор. Такие же настройки находятся в
«Качестве и звуке». Выбор в обоих местах общий и сохраняется автоматически.
Во время работы переключатели заблокированы: сначала остановите очередь.

Нажмите «Проверить» для короткого реального кодирования H.264. «Подробнее»
показывает модели адаптеров, версии драйверов и ошибки каждого кодировщика.
Установленный в FFmpeg кодировщик сам по себе не означает, что видеокарта
поддерживает его. При неудаче лаунчер сообщает причину и использует CPU.
Отчёт `hardware-diagnostics.json` сохраняется рядом с настройками.

NVIDIA P106-100 не имеет блока NVENC, поэтому не может кодировать H.264 через
NVENC. Наличие CUDA-ядер этого не меняет. NVIDIA подтверждает ограничение:
https://forums.developer.nvidia.com/t/nvenc-and-gp106-100/67850/6
На компьютере с P106-100 можно проверить встроенную Intel Graphics через
Quick Sync, если она есть и доступна драйверу. Иначе используйте процессор.
В этой версии аппаратное декодирование или обработка через CUDA не добавлены.

«Точный» режим использует два прохода на CPU независимо от переключателя.
Для GPU выбирайте обычный быстрый режим подготовки. Совместимое исходное
H.264/yuv420p копируется без повторного кодирования; в этом случае GPU не нужен.
Декодирование и масштабирование выполняются на CPU даже при кодировании на GPU.

## Обновление

1. Остановите очередь и дождитесь остановки. Закройте старый лаунчер.
2. Для EXE установите `KinoTime-Setup-1.3.2.exe` либо замените самостоятельный
   `KinoTime.exe`. Обе программы находятся в `KinoTime-Windows-1.3.2.zip`.
3. Для Python-версии замените файлы из `Launcher/` архива
   `KinoTime-Hardware-1.3.2.zip` в корне папки лаунчера с сохранением структуры.
4. Запустите лаунчер, выберите оборудование, нажмите «Проверить» и продолжите
   подготовку. Готовые MP4 используются повторно; не удаляйте папки кэша.

Обновление 1.3.2 касается только лаунчера. Серверное обновление не требуется.
Настройки и видео не входят в архив; база данных бота не меняется.
Если ранее уже обновлялись до 1.3.1, сохраняется поддержка длинных названий
и независимых очередей нескольких компьютеров.

Настройки EXE: `%LOCALAPPDATA%\KinoTime\Launcher`. Настройки Python-версии
остаются в прежней папке `tools`, если не задан `KINOTIME_STATE_DIR`.

Проверки выполняются на Intel Iris Xe / i7-1355U и CPU с синтетическими видео.
Поведение NVIDIA/AMD и сценарий P106-100 проверяются через имитацию драйверных
ответов. Реальное кодирование на P106-100 на этом компьютере не проверялось.
