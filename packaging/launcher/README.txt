JACKETT И ВЫБОР ИСТОЧНИКОВ 1.4.7
Откройте «Торренты → Помощник выбора раздачи → Источники…».
Нажмите «Запустить встроенный», затем «Настроить трекеры». В открывшемся
окне Jackett добавьте LostFilm, RuTracker или другие нужные источники и
войдите в свои аккаунты, если трекер этого требует. Вернитесь в лаунчер,
нажмите «Обновить список», отметьте нужные источники и «Сохранить выбор».
Для поиска только в LostFilm снимите Rutor и остальные галочки.
Jackett включён в EXE; отдельная установка и права администратора не нужны.
Встроенный компонент работает локально на порту 9118, с отдельными настройками.
Если выбранные источники требуют его запуска, он запускается при поиске.
Можно подключить свой локальный Jackett по адресу и API-ключу.
Выбор источников сохраняется. Ключ своего Jackett хранится только до закрытия
окна поиска; ключ встроенного Jackett и аккаунты хранятся в его локальной папке.
Jackett получает .torrent через настроенный аккаунт; файл передаётся в обычную
торрент-очередь, затем в очередь проектов. Кода карточки по-прежнему не нужно.
Некоторые источники возвращают мало сведений. Обязательные условия остаются
строгими: отсутствие данных о рекламе не означает отсутствия рекламы.
Если условие не нужно, снимите его галочку. «Показать исключённые» объясняет отбор.
LostFilm может отдавать английские названия: используйте оригинальное название.
Подробная инструкция: docs/JACKETT_1_4_7.md в исходном проекте.

ОБЯЗАТЕЛЬНЫЕ УСЛОВИЯ И СТРАНИЦЫ ПОИСКА 1.4.5
Поиск больше не ограничен восемью описаниями. По умолчанию проверяются до
10 страниц результатов Rutor; поле «Страниц поиска» позволяет выбрать от 1 до 20.
Заполненные условия отбирают результаты, а не только влияют на порядок строк.
В основной таблице остаются совпадающие название, год, сезон, разрешение,
максимальный размер и озвучка. При включённом условии отсутствия рекламы
неподтверждённые варианты исключаются. Поля размера и разрешения можно очистить.
«Показать исключённые» раскрывает отклонённые варианты с причинами. Их нельзя
передать в очередь без изменения условий и повторной проверки.
«Применить условия» пересчитывает отбор; при смене названия, сезона, года,
разрешения или числа страниц запускается новый поиск для чтения нужных описаний.
Сообщение «Лучший вариант» больше не показывается при отсутствии подходящих.
Код карточки сериала — назначение для добавления, он не является фильтром поиска.

ПОИСК И АВТОПОДГОТОВКА 1.4.3
Откройте «Торренты → Помощник выбора раздачи». Теперь первым открывается поиск.
Введите название, год, нужную озвучку, разрешение и максимальный общий размер.
Сезон 0 означает фильм. Для сериала укажите сезон и код существующей карточки.
«Найти варианты» получает описания и magnet-ссылки автоматически.
«Найти и подготовить» дополнительно выбирает лучший подтверждённый вариант,
сверяет список файлов и запускает скачивание и подготовку в торрент-очереди.
Поиск обходит страницы в пределах выбранного лимита. Страницы могут быть недоступны.
При разных годах, неизвестных параметрах, рекламе, отсутствии раздающих,
пропусках серий или нескольких фильмах автовыбор останавливается для проверки.
По умолчанию используется зеркало cat.dark-proxy.ru из расширения Firefox «Rutor».
Программа повторяет способ обращения расширения; Firefox запускать не требуется.
Поле «Адрес Rutor» позволяет указать другой адрес сайта с той же структурой.
Живой поиск, чтение описаний и получение magnet-ссылок проверены на «Орвилле».
Программа не меняет сетевые настройки компьютера.
Отправка и публикация остаются отдельными действиями существующего лаунчера.
Ручной разбор описаний доступен через «Вставить описание вручную».

ПРОЕКТЫ: НЕСКОЛЬКО СЕРИАЛОВ ОДНОВРЕМЕННО
В «Источнике» выберите папку и качества. Для одного сериала включите
«Один проект / сериал», затем откройте «Проекты» и добавьте источник.
Пока идёт рендер, выбирайте другую папку и добавляйте следующий проект.
По умолчанию работают два проекта одновременно; доступны от 1 до 4 обработок.
Проекты чередуются после одной серии в одном качестве со всеми озвучками.
Видеоряд качества создаётся один раз для выбранных озвучек.
У каждого проекта свои прогресс, пауза, продолжение и переключатель приоритета.
После перезапуска незавершённые проекты восстанавливаются на паузе.
Для сезона существующего сериала перед добавлением заполните № сериала
из каталога и номер сезона. Одна папка проекта должна содержать один сезон.
Для обычного импорта оставьте эти поля пустыми.
По окончании рендера нажмите «Создать карточки», оформите их в WEB,
затем нажмите «Отправить». Telegram отправляет только один проект за раз;
другие проекты могут продолжать рендер. Обновление сервера не требуется,
если текущий сервер поддерживает импорт сезонов и несколько компьютеров.
Коды подключения не сохраняются. Для создания карточек и отправки после
перезапуска потребуется свежий код /desktop. Рендер работает без подключения.
Подробности и ограничения: docs/MULTI_PROJECTS_1_4.md в исходниках проекта.

KinoTime-Setup-1.4.1.exe — установщик с ярлыком и удалением программы.
Установка в профиль текущего пользователя; права администратора не требуются.
KinoTime.exe — самостоятельный вариант без установки. Можно перенести один EXE

ПЕРВОЕ ПОДКЛЮЧЕНИЕ
1. Установите Telegram Desktop и войдите в свой аккаунт администратора бота.
2. В боте выполните /desktop. В разделе «Настройки» укажите адрес панели и код.
   Код действует 48 часов, остаётся только в памяти до закрытия лаунчера.
3. Выберите исходники и качества, затем запустите подготовку без отправки.
4. Проверьте карточки в веб-панели. Отправку запускайте отдельно, когда готовы
   оставить компьютер разблокированным. Лаунчер управляет Telegram Desktop.
Для торрент-очереди отдельно нужен qBittorrent 5.x с локальным Web UI.
Ни Telegram Desktop, ни qBittorrent не включены в этот пакет.

ОБОРУДОВАНИЕ
Выбор «Кодирование» находится прямо в «Очереди», а также в «Качестве и звуке».
Автоматически: проверка H.264 NVIDIA NVENC → Intel Quick Sync → AMD AMF → CPU.
Можно выбрать конкретного производителя или процессор. Проверка выполняет
короткое реальное кодирование, а не только поиск названия кодировщика.
Если выбранный GPU недоступен или не справился с исходником, подготовка
повторяет кодирование через процессор. Готовые копии сохраняются.
Нужны совместимое оборудование и установленный драйвер производителя.

Экономный: примерно четверть логических потоков CPU, пониженный приоритет.
Сбалансированный: примерно половина потоков CPU — режим по умолчанию.
Максимальная скорость: доступны все логические потоки CPU.
Это бюджет потоков FFmpeg, а не жёсткий процент загрузки всей системы.
Графическое кодирование может дополнительно нагружать GPU и драйвер.
Выбор оборудования и нагрузки сохраняется автоматически. Во время работы
очереди переключение заблокировано; сначала остановите подготовку.
«Проверить» запускает тест, «Подробнее» показывает модель, драйвер и ошибки
FFmpeg. Диагностика сохраняется в hardware-diagnostics.json рядом с настройками.
У NVIDIA P106-100 нет блока NVENC: эта модель не может кодировать H.264 через
NVENC. CUDA-ядра не заменяют этот блок. Для неё остаётся CPU либо другой GPU
с рабочим кодировщиком (например, встроенная Intel Graphics с Quick Sync).

Ускоряется кодирование H.264. Декодирование и масштабирование выполняются на
CPU с ограничением потоков. «Точный» режим использует два прохода на CPU.
Совместимый исходный H.264/yuv420p копируется без повторного кодирования.
Каждое более низкое выбранное качество готовится отдельно; один видеоряд
используется для всех выбранных озвучек данного качества.
До 1000 вариантов MP4 на один импорт. Число вариантов = сумма по исходникам
(доступные выбранные качества × включённые озвучки).

НАСТРОЙКИ И ОБНОВЛЕНИЕ
Настройки установленного и самостоятельного EXE:
%LOCALAPPDATA%\KinoTime\Launcher
Адрес панели, выбранные папки, режим оборудования и нагрузки сохраняются.
Коды подключения и пароль qBittorrent не записываются в настройки.
На новом компьютере нужно подключиться заново и выбрать его локальные папки.
Папки видео, готовые копии и журналы очереди остаются рядом с исходниками
или в выбранной рабочей папке торрентов. Не удаляйте их при переносе очереди.
Обновление установщиком сохраняет настройки. Удаление программы не удаляет
настройки пользователя и видео. Серверное обновление поставляется отдельным ZIP. База бота в архивы не входит.

НЕСКОЛЬКО КОМПЬЮТЕРОВ (НОВОЕ В 1.3.0)
Сначала установите серверное обновление KinoTime-Server-1.3.3.zip
и полностью перезапустите бота. Затем обновите все подключённые лаунчеры.
Для каждого ПК получите отдельный код /desktop и задайте понятное имя
в «Настройках». В веб-панели → «Лаунчер» выберите нужный компьютер.
У каждого ПК свои папки, качества, статус, черновики и история команд.

При переходе со старого Python-лаунчера на EXE на том же компьютере нажмите
«Перенести настройки старого лаунчера» и выберите его tools/launcher-settings.json.
Это сохраняет идентификатор компьютера для продолжения существующих очередей.
После переноса получите новый код /desktop. Не переносите настройки и журналы
очереди на второй компьютер для одновременной отправки тех же материалов.

Перед импортом лаунчер вычисляет SHA-256 каждого готового MP4. Это дополнительное
чтение диска; неизменившиеся файлы используют сохранённую контрольную сумму.
Точные копии у одного администратора не отправляются параллельно. Уже принятый
файл используется повторно по Telegram file_id. Разные версии видео могут
иметь разные байты и потребуют отдельной отправки; названия не служат проверкой.

Если Telegram начал загрузку, отметка хранится на сервере даже при обрыве связи.
Автоматический повтор не выполняется. Сначала проверьте отсутствие отправки
и загрузки в Telegram, затем используйте «Разрешить безопасный повтор» на том
компьютере, с которого она запускалась. Нельзя сбросить отправку другого ПК.
Подготовка на разных ПК независима; один лаунчер на профиль Windows.

ОБНОВЛЕНИЕ 1.3.4: МЕСТО НА ДИСКЕ
В Настройках включена автоочистка промежуточного видеоряда после сборки озвучек.
При нехватке места можно удалять учтённые MP4, уже подтверждённые ботом.
Исходники и непринятые файлы сохраняются. Автоочистку можно выключить.
Резерв по умолчанию — 2 ГиБ. Очередь ждёт освобождения места и продолжает сама;
если запись прервалась из-за нехватки места, текущий незавершённый MP4 создаётся заново.
Для повторной отправки удалённых принятых копий потребуется повторная подготовка.
Старые неучтённые кеши не удаляются массово. Telegram и серверные файлы не удаляются.
Кбит/с — целевой битрейт видео. Реальная скорость показывается отдельно: × и кадр/с.

ПОТОЧНАЯ ПОДГОТОВКА 1.3.5
В очереди появилась отдельная кнопка «Подготовка → отправка → очистка».
Сначала обновите сервер файлами из Server и перезапустите бота.
Каждый готовый MP4 отправляется в Telegram сразу, после подтверждения бота
его зарегистрированные копии удаляются, затем готовится следующий вариант.
Все серии/варианты одного проекта остаются в одной WEB-карточке.
В массовом режиме каждый исходник по-прежнему создаёт отдельную карточку.
До завершения проекта публикация заблокирована. Оформление и публикация — в WEB.
При ошибке неподтверждённые копии сохраняются; повторите ту же кнопку с теми же
исходниками и настройками. Подтверждённые варианты повторно не обрабатываются.
Windows должна быть разблокирована, тихая подготовка выключена. Не используйте
Telegram параллельно отправке. Исходники не удаляются. Обычная подготовка без
отправки работает отдельно. Нужен запас места для текущего видео и MP4 с озвучкой.
